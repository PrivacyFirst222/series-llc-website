# Capacity-output visual review

Four multi-member variants generated by the real offline routes total 158 pages (39 member, 40 member-S, 39 manager, 40 manager-S). Automated extraction checks every owner name and saved contribution in all four. Visual review is deliberately scoped to 12 rendered pages containing the hundredth owner: signature, owner/contribution table tail, and beneficiary table tail in each variant. All twelve PNGs were opened and inspected. Owner100 is present and legible, with 1% and $100 on each owner schedule. This is not a whole-document layout audit. Existing pagination can split a signature block and leave a contributed-assets header before a page break; this batch does not repair the renderer or claim those issues resolved. No master wording changed.
