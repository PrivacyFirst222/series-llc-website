# Event map — what happens to these people, and what governs it

Gated by `docs/event-map.py`. The other checks read the document and ask whether
what is there is sound. This one starts from the world and asks whether the
document answers it, because the fault I cannot see is the **absence**: a
provision that is missing produces no text to read, no diff, and no failing
check. Adam's best catches this month were all of that shape — "where is the
competition section in the member-managed partnership form", "why is there a
waiver of participation rights in a single-member agreement", "do we have a
single-member S corporation form". Every one was a question about something that
was not on the screen.

So each row is an event that happens to a real company, its source in Chapter 605
or in life, and the provisions that govern it **in each form separately** — the
forms differ, so a section that answers the event in the multi-member document
proves nothing about the single-member one.

`none` is a legitimate answer and must carry a reason in the note. It is also the
column worth reading first: an event no provision reaches is either correctly
left to the Act or a hole, and the map cannot tell which. That is Adam's call,
which is the point of writing it down instead of leaving it unwritten.

`scp` manager-managed S corporation · `mbr` member-managed ·
`mbs` member-managed S corporation · `sgs` single-member S corporation ·
`sgm` member-managed single-member.
